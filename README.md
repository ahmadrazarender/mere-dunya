# Meri Duniya Hain Aap — Rumi to Gull

A five-page, responsive romantic website made with plain HTML, CSS and JavaScript.

## Files
- `index.html` — Home page
- `moments.html` — Shared little moments
- `letter.html` — Personal letter
- `comfort.html` — Rumi's comfortable, playful side
- `promises.html` — A few honest intentions
- `style.css` and `script.js` — Shared design and navigation

## Publish with GitHub Pages
1. Create a public GitHub repository.
2. Upload all files in this folder to the repository's root (not inside another folder).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main** and **/(root)**, then click **Save**.
6. Wait a minute or two. GitHub will show the website URL in the Pages section.

The website uses Google Fonts and Unsplash image links, so an internet connection is needed for those external assets.
